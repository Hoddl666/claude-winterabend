# Winterabend

A Christmas winter-night theme for the Claude desktop app, made as a Claude Code mod.

- A robin in a Santa hat sits on a wooden sign that shows the context window fill and how long the prompt cache stays warm, with a burning candle.
- Two stockings show your 5-hour and weekly usage limits, with their reset times.
- On the left: a decorated Christmas tree, a snowman and a street lamp. On the right: a lit A-frame cabin, snowy pines and the moon.
- Snow falls all the time, and the snowfield rises as your context window fills.
- The chat bubbles are seasonal too.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install winterabend --marketplace Hoddl666/claude-winterabend
```

Answer `y` to add the marketplace, then pick a scope (user is the first one).

From a shell:

```
claude plugin install winterabend --marketplace Hoddl666/claude-winterabend
```

In the desktop app, where `/plugin` does not run: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `Hoddl666/claude-winterabend`, then **Add plugin**.

## Use

- `/winterabend` turns the theme on again, for example after another theme was chosen.
- `/winterabend rand 240` starts the left-hand scene 240 px from the window edge, so it sits next to an open sidebar. Pick the number that fits your sidebar.
